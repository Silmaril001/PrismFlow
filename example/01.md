Role: 你是一个顶尖的 2D Shader 编写专家。请用纯 2D 的 UV 数学计算，复刻经典的“Windows 95 飘动徽标”效果。
绝对禁令: 严禁使用任何 3D Raymarching、SDF 相机或 rd, ro。全部在 2D 屏幕空间完成。

全局变量:
必须使用 uniform float u_time; 和 uniform vec2 u_resolution;。将 UV 居中并修正长宽比。

背景与画布:
背景颜色设定为经典的深青色 (Teal，约 vec3(0.0, 0.5, 0.5))。

核心形变 (Wave Distortion):
对整个 UV 坐标空间施加一个基于正弦波的扭曲，产生旗帜飘动的效果：y 轴需要叠加基于 x 轴和 u_time 的 sin() 偏移。同时让整个徽标带有轻微的向右倾斜（Shear / 旋转）。

右侧实体部分 (The Windows Panes):

在扭曲后的 UV 空间中，绘制一个带有粗大黑色十字边框的四宫格田字形。

四个格子的颜色分别为：左上珊瑚红(vec3(0.9, 0.3, 0.2)), 右上草绿(vec3(0.5, 0.7, 0.2)), 左下天蓝(vec3(0.3, 0.6, 0.8)), 右下明黄(vec3(1.0, 0.8, 0.1))。

左侧像素拖影部分 (The Trailing Pixels):

在田字格的左侧区域，使用 floor() 函数将 UV 空间离散化为马赛克网格 (Grid)。

利用基于网格坐标的伪随机 Hash 函数，决定该网格是否显示方块。越往左，显示方块的概率越低（使用 smoothstep 控制密度渐变）。

散落方块的颜色分配：随机生成黑色方块，或者根据其所在的 Y 轴高度，继承对应田字格行的颜色（上半部分多为红色/黑色，下半部分多为蓝色/黑色）。

让这些马赛克网格整体跟随徽标一起进行正弦波飘动。

请输出结构清晰、包含注释的 GLSL 代码。
