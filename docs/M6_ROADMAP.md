# M6 里程碑路线图（日志页 + 数据分析后台）

> 这是当前 chat 的长期主线记忆文件。  
> 规则：M6 验收通过前，不推送到远端 Git。

## M6 总目标

1. 新增“生成日志页”：记录并展示所有用户生成过的 GLSL（含详情查看）。
2. 新增“数据分析后台”：可查看单位时间访问量、生成量、成功率、延迟等。

## M6.1（当前阶段）：生成日志页

目标：

1. 后端提供日志列表与详情接口（分页）。
2. 前端新增日志广场页（类似收藏页）与日志详情页。
3. 主界面提供日志页入口。

验收标准：

1. 能查看最近生成日志，支持分页。
2. 点开单条日志可查看完整 GLSL 和元信息。
3. 不影响现有主流程、收藏页功能。

状态：`completed`
